### 贡献方式

在开始提交 Pull Request 之前，请先阅读[贡献指南](https://github.com/opencv/opencv/wiki/How_to_contribute)。

#### 指南要点：

* 一个 Pull Request 对应一个问题；
* 选择正确的目标分支；
* 包含测试与文档；
* 提交前清理「手滑」式的无效提交；
* 遵循[代码风格指南](https://github.com/opencv/opencv/wiki/Coding_Style_Guide)。
